# CropPilot

CropPilot is a university project for agricultural decision support, connecting farmers, extension officers, and administrators.

## Phase 1

- User registration and email/password login
- Input validation and role-specific registration fields
- Farmer and extension officer dashboards
- Protected admin dashboard for reviewing registrations
- Admin access granted to verified accounts, not selected during registration

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
